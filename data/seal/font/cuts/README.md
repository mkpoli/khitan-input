# Xuanyi block cuts

Sixteen 512-square colour cuts, one per block, centred on black with a small margin. Each is
cropped from the rectified cover photograph, so the stone tone and the paint are both visible for
redrawing or vectorising. `masks/` holds the optional pale-paint mask of the same crop.

Source: Tonyxy1992, *Epitaph of Empress Xuanyi of Liao*, Wikimedia Commons, 2015-08-05, CC BY-SA
4.0. The cuts are offered under the same licence. `docs/seal-cuts.png` is the contact sheet.

```sh
uv run scripts/build_seal_cuts.py
```
