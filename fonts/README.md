# Fonts

- `NovaN176Running-Regular.ttf`, `.woff2`: 96 running-script forms cut from folio 9 of the Khitan
  large-script manuscript Nova N 176. Page-local Private Use code points U+E600–U+E65F; four
  identified forms also answer at BabelStone points U+E05A, U+E28F, U+E396 and U+E03C. The source
  photograph is public domain; the traced outlines derive from it. See
  [data/running/README.md](../data/running/README.md).
