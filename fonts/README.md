# Fonts

Qingling Seal encodes the 36 distinct characters on the Daozong and Xuanyi covers at 38 Unicode code points. Sixteen proposed designs extend its coverage to 54 code points.
Both formats support continuous weights from 200 to 800, with Regular at 400.
The TTF and WOFF2 include the alternate Xuanyi carvings of U+18C64, U+18CA6 and U+18C9C under `ss01`.
